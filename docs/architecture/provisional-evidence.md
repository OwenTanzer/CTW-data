# Discovering and using provisional evidence

Discovery is automatic when relevant; adoption as a model input is deliberate.
Moving a map out of production lookup must not make useful work invisible.

For a battlefield-preparation or terrain question, check the compact catalog
`development_discovery` routes after the production map identity. Match the named
map/known alias and resolve an exact variant before a query. Surface a matching
candidate with its status, scope and entry link even if the user did not ask for
“development data.” Do not scan unrelated evidence collections or claim that an
unlisted map has no evidence. Ambiguous names require variant resolution; a
shared asset prefix is not an exact identity.

For Cold Mires (`chs_wastes_coast_a_01`), explain that a reproducible terrain
hypothesis is available and that alignment, water behavior, cover and passability
remain unverified. Its README and point/region/summary query can be inspected
without additional permission. Summarize unknowns alongside any observation.
A question about battle preparation or this map is sufficient reason to inspect
it; “opt-in” is not a requirement that the user learn a hidden catalog keyword.

| Use | Required treatment |
| --- | --- |
| Find existing work or prepare an experiment | Surface and inspect the qualified candidate; retain exact map and evidence pins |
| Describe the candidate drawing | Say “the candidate map shows…”; preserve orientation and semantic qualifications |
| Suggest a tactical hypothesis | State the assumed feature/transform and which observation could disconfirm it |
| Compute a prediction using provisional geometry | Declare the particular assumption in scenario inputs and carry it into results; otherwise omit that dependent calculation |
| Assert verified passability, concealment or a traversable route | Requires supporting scoped evidence; blank/unknown is never passable or absent |

A consumer may voluntarily exclude provisional evidence from calculations. It
must still report a relevant available candidate and the limitation rather than
silently claiming there is no terrain information. Automatic discovery does not
alter the production authority hierarchy. These are routing and presentation
instructions, not a claim that an Adviser terrain adapter already exists.
