# PR #17 review repair — active objectives and generated documentation

The original 9.0 refresh used legacy victory composition even though the shipped dispatch bypasses it for all 109 playable factions. This repair uses the active configuration for 108 direct faction entries and two lord variants of Schwartzhafen (Vlad/Isabella). It produces 1,175 initial objectives and 4,074 conditions over 110 selectors, replacing the incorrect 772 / 2,458 result.

## Source and representation

`data/campaign_map/objective_source_exports/source_manifest.json` records verified 9.0/build 25507028 evidence: the active configuration, helper definitions, Archaon narrative dependency and legacy dispatch. The raw supplemental source was retained on `checkpoint/victory-config-9.0-review`. The updated extractor requests these dependencies for 9.0 only.

The bounded parser never evaluates Lua. It accepts declarative tables and reviewed helper semantics; unrecognized syntax, helper names, source fingerprints or the pinned helper revision fail validation. Lua zero truthiness is preserved. Group references resolve to explicit region/province keys. The independent Nagash, Khazrak and Vlad/Isabella expectations are transcribed from source, rather than generated by the parser under test.

Schema 1.2 adds `variant_key`, `helper_key`, `objective_boundaries` and matching objective manifest/schema inventories. Eight objective boundaries retain runtime unit-size scaling with null numeric values. 682 scripted objectives preserve their completion keys without asserting listener progress. Four initial Archaon long-victory objectives record later chosen-path additions as a boundary. Rewards, crisis simulation and multiplayer objectives remain excluded.

## Existing army evidence

The rebuilt geography is identical across campaigns, factions, provinces, regions, region points and embedded map assets. `rebind-start-evidence.py` checks all their rows and all existing compact evidence hashes before creating a new work-only source manifest. The manifest retains the original extraction atlas hash and records the comparison. No new binary extraction or runtime game observation is claimed. Starting-position enrichment preserves atlas schema 1.2 and the existing army data: 109 primary starts, 118 generals, five partner overrides and 572 settlement controls.

The base builder pins GeoPackage timestamps to the extraction time so rebuilding the same source produces the same bytes; the objective repair was rebuilt twice with identical GeoPackages. The starts builder retains the correct 9.0 audit date.
